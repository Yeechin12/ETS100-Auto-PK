# 单词 PK 助手

Android 辅助应用：通过屏幕捕获和 ML Kit OCR 识别 e听说中学单词 PK 题目，并可使用无障碍服务自动点选答案。词义数据覆盖用户提供的教材 Unit 1–6 词表，并支持导入自定义词表。

## 技术栈

- Java / Android 原生
- Google ML Kit Text Recognition（英文与中文）
- Android MediaProjection 屏幕捕获
- Android Accessibility 自动点击

## 构建

需要 JDK 17 或兼容版本，以及 Android SDK（API 36）。

```powershell
.\gradlew.bat assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。

签名说明：仓库不包含 `debug.keystore`（签名材料不提交，见 `.gitignore`）。根目录没有该文件时使用 AGP 自动生成的默认调试签名，可直接出包；如果你希望多台机器共用同一个调试签名，把 `debug.keystore` 放到项目根目录即可自动启用。

## 识别区域

默认按屏幕高度比例切两条带定位题干（22%–33%）与选项（34%–70%）——这是旧行为，在常规比例的竖屏手机上工作正常。若按默认区域认不出题面（提示"选项区没有识别到文字"或"未识别到中英文题干"），应用会用整屏 OCR 探一次版面结构：把行框聚成"行"，找一段字号相近、行距正常的连续行作为选项区，其上方紧邻的文字作为题干，然后改用定位出来的区域（该探测帧不答题，之后每 3 秒最多重探一次、最多 8 次）。检测结果与默认比例区域差异小于屏高 6% 时不切换，因此原本正常的机型行为不变。

## 使用

1. 在 Android 设置中启用本应用的无障碍服务。
2. 回到应用选择运行模式（自动点击 / 仅显示答案），点"开始识别"。
3. Android 13 及以上会先申请通知权限：拒绝也能识别，但状态栏通知会被静默，也就没有通知栏里的"停止识别"入口。
4. 授权屏幕捕获后切到 e听说中学的单词 PK 页面。

运行期间可直接在应用里切换运行模式，会立即同步给正在识别的服务，不需要重新授权录屏。结束识别可用应用内的"停止识别"、通知栏的"停止识别"，或系统状态栏的停止共享。

若识别提示"词表未覆盖：…"，说明该题的选项不在词表里，提示里会列出识别到的选项文字，按下面的格式补进自定义词表即可。

## 自定义词表

内置词表是 `app/src/main/assets/vocab.tsv`，共 198 条，覆盖 Unit 1–6。运行时可在主界面点"导入自定义词表（TSV）"选择文件；导入的条目会追加到内置词表，同名单词覆盖内置释义，识别过程中立即生效（无需重启识别）。

格式与内置词表一致，UTF-8、每行一条，单词与释义之间是制表符（Tab），多个释义用半角分号分隔，`#` 开头的行会被忽略：

```
teenage	十几岁的;青少年的
first-aid kit	急救箱
```

导入文件保存在应用私有目录的 `vocab-extra.tsv`，大小上限 512 KB；解析不出任何合法行时会拒绝导入，不会破坏已有词表。
